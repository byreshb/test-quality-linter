# TQL003 NoAssertion

**Default severity:** WARN

## What it catches

A test method that never asserts anything. The method is fine when it contains, directly or in
a helper method of the same class, any of:

- an assertion of JUnit 4 or 5, TestNG, AssertJ, Hamcrest, Google Truth or Playwright
  (`assertEquals`, `assertThat(...)`, `assertThrows`, `assertAll`, `fail`, ...);
- a Mockito or EasyMock verification (`verify`, `verifyNoInteractions`, `inOrder`, ...);
- a call whose name starts with `assert`, `verify`, `expect`, `should` or `check`, which is how
  custom assertion helpers are usually named;
- a statically imported method from one of the configured `packages`;
- a method named in the `methods` option.

A JUnit 4 `@Test(expected = ...)` or TestNG `@Test(expectedExceptions = ...)` is an assertion
made by the framework, so those tests are skipped.

## Why it matters

A test without an assertion passes as long as nothing throws. It exercises code, which is why
coverage tools love it, but it only proves the absence of an exception. Generators produce these
in bulk: call the method, assign the result, done.

## Bad

```java
@Test
void savesOrder() {
  Order saved = service.save(new Order("widget", 2));
  System.out.println(saved);
}
```

## Fixed

```java
@Test
void savesOrder() {
  Order saved = service.save(new Order("widget", 2));
  assertThat(saved.id()).isNotNull();
  assertThat(repository.find(saved.id())).contains(saved);
}
```

If the intent really is "does not throw", say so:

```java
@Test
void acceptsEmptyInput() {
  assertDoesNotThrow(() -> service.save(new Order("", 0)));
}
```

## Options

| Option | Type | Default | Meaning |
|--------|------|---------|---------|
| `methods` | list of strings | empty | Extra method names that count as assertions, for example `ensureSaved`. |
| `packages` | list of strings | JUnit, TestNG, AssertJ, Hamcrest, Truth, Playwright, Mockito, EasyMock packages | A method statically imported from one of these packages counts as an assertion whatever its name. |

```yaml
rules:
  TQL003:
    options:
      methods: [ensureSaved, mustContain]
      packages: [com.acme.testing]
```
