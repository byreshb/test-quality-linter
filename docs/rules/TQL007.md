# TQL007 SwallowedException

**Default severity:** WARN

## What it catches

A `catch` block in a test that hides the exception: an empty block, or a block whose only
statements print or log (`e.printStackTrace()`, `System.out.println(...)`, `log.error(...)`,
`LOGGER.warn(...)`).

The classic JUnit 3 and 4 pattern is recognised and left alone, because the `fail()` makes the
empty catch an assertion:

```java
@Test
void rejectsNegativeQuantity() {
  try {
    new Order("widget", -1);
    fail("expected IllegalArgumentException");
  } catch (IllegalArgumentException expected) {
  }
}
```

## Why it matters

An exception thrown by the code under test is the clearest possible test failure, and a catch
block that prints it turns that failure into a green test with some console noise nobody reads.

## Bad

```java
@Test
void importsFile() {
  try {
    importer.load(Path.of("orders.csv"));
  } catch (IOException e) {
    e.printStackTrace();
  }
  assertEquals(3, repository.count());
}
```

## Fixed

Let it propagate:

```java
@Test
void importsFile() throws IOException {
  importer.load(Path.of("orders.csv"));
  assertEquals(3, repository.count());
}
```

Or, if the exception is the expected outcome, assert it:

```java
@Test
void reportsMissingFile() {
  IOException e =
      assertThrows(IOException.class, () -> importer.load(Path.of("missing.csv")));
  assertThat(e).hasMessageContaining("missing.csv");
}
```

## Options

None.
