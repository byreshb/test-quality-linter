# TQL001 TautologicalAssertion

**Default severity:** ERROR

## What it catches

An assertion whose two sides are the same expression, or whose operand is a constant that
makes the assertion unable to fail:

- `assertEquals(x, x)`, `assertSame(x, x)`, `assertArrayEquals(a, a)`,
  `assertIterableEquals(l, l)`, with or without a JUnit 4 leading or JUnit 5 trailing message.
- `assertThat(x).isEqualTo(x)`, `.isSameAs(x)`, `.containsExactlyElementsOf(x)`,
  `.hasSameElementsAs(x)` and similar AssertJ or Truth comparisons, anywhere in the chain.
- Hamcrest `assertThat(x, is(x))`, `equalTo(x)`, `sameInstance(x)`, also nested as
  `is(equalTo(x))`.
- `assertTrue(true)`, `assertTrue(x == x)`, `assertTrue(x.equals(x))`, `assertFalse(false)`,
  `assertFalse(x != x)`, `assertThat(true).isTrue()`.
- `assertNotNull(new Foo())`, `assertNotNull("literal")`, `assertThat(new Foo()).isNotNull()`,
  `assertThat(new Foo(), notNullValue())`: a freshly created object or a literal is never null.

Expressions are compared structurally after removing parentheses, so `x` and `(x)` match while
`x` and `this.x` do not.

## Why it matters

These assertions are green whatever the code under test does. They usually appear when a
generator (or a hurried human) needs "an assertion" to make a test look complete, and they hide
the fact that the test proves nothing. Deleting the assertion would at least make the gap
visible; TQL003 would then report the test as having no assertion.

## Bad

```java
@Test
void savesOrder() {
  Order order = service.save(new Order("widget", 2));
  assertEquals(order, order);
  assertNotNull(new Order("widget", 2));
  assertTrue(true);
}
```

## Fixed

```java
@Test
void savesOrder() {
  Order order = service.save(new Order("widget", 2));
  assertEquals("widget", order.product());
  assertEquals(2, order.quantity());
  assertTrue(repository.exists(order.id()));
}
```

## Options

None.

## Suppressing

Add `// tql:ignore TQL001` on the offending line, or `@SuppressWarnings("tql:TQL001")` on the
method or class (delivery step 5).
